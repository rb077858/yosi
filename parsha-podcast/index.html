🎧 פודקאסט פרשת השבוע

בוחרים פרשה, האפליקציה מביאה את הטקסט המלא מספריא, ומכינה ממנו פודקאסט להאזנה – גם בלי אינטרנט.

1. בחירת פרשה

2. פודקאסט ב-NotebookLM

Google לא מאפשרת לאפליקציה חיצונית לפתוח מחברת ב-NotebookLM בשבילכם, אז יש כאן כמה לחיצות ידניות – אבל הטקסט כבר מוכן.

פתיחת NotebookLM ↗
  1. ב-NotebookLM: מחברת חדשה (Create new).
  2. במסך הוספת מקור: בוחרים "טקסט שהועתק" (Copied text) ומדביקים. או: משתפים את הקובץ ישר לאפליקציית NotebookLM / מעלים את הקובץ שנשמר.
  3. בלשונית Studio: לוחצים על העיפרון ליד סקירה קולית (Audio Overview), בוחרים שפה (למשל עברית) ומדביקים את ההנחיה שלמטה. לוחצים יצירה. זה לוקח כמה דקות.
  4. להאזנה בלי אינטרנט: באפליקציית NotebookLM לוחצים ⋮ ליד הסקירה ← הורדה. באתר: ⋮ ← Download.

2. פודקאסט אוטומטי עם Gemini

כאן הכל קורה לבד: Gemini מקבל את הטקסט של הפרשה כמקור יחיד, כותב שיחה בין שני מגישים, ומקריא אותה בשני קולות. בסוף מקבלים קובץ שמע לשמירה בטלפון.

מפתח Gemini (פעם אחת בלבד)

מקבלים מפתח בחינם ב-aistudio.google.com/apikey ← Create API key, ומדביקים כאן. המפתח נשמר רק בטלפון שלכם ונשלח רק ל-Google.
