# פודקאסט פרשת השבוע

אפליקציה לטלפון: בוחרים פרשה, והאפליקציה מביאה את הטקסט המלא של הפרשה מספריא ומכינה ממנו פודקאסט של שני מגישים, להאזנה גם בלי אינטרנט.

כתובת: **https://yosi.reembir.com/parsha-podcast/**

טיפ: בדפדפן בטלפון אפשר לבחור "הוספה למסך הבית", ואז האפליקציה נפתחת כמו כל אפליקציה אחרת.

## איך משתמשים

1. בוחרים פרשה. הפרשה של השבוע מופיעה ראשונה ומסומנת ב-⭐. אפשר לבחור עברית, אנגלית או את שתיהן.
2. לוחצים **"הבאת הטקסט"**.
3. בוחרים אחת משתי דרכים:

### דרך א: NotebookLM (חצי ידני)
Google לא מאפשרת לאפליקציה חיצונית ליצור מחברת ב-NotebookLM בחשבון פרטי, אז יש כמה לחיצות ידניות:
- **"שיתוף הטקסט כקובץ"** ← בוחרים ב-NotebookLM. או: **"העתקת הטקסט"** ← ב-NotebookLM: מחברת חדשה ← "טקסט שהועתק" ← הדבקה.
- בלשונית Studio: **סקירה קולית** (Audio Overview). אפשר לבחור עברית ולהדביק את ההנחיה המוכנה מהאפליקציה.
- להאזנה בלי אינטרנט: ⋮ ליד הסקירה ← **הורדה**.

### דרך ב: אוטומטית עם Gemini
הכל קורה לבד: Gemini מקבל את הטקסט של הפרשה כמקור יחיד, כותב שיחה בין שני מגישים ומקריא אותה בשני קולות. בסוף לוחצים **"הורדה לטלפון"** ומקבלים קובץ MP3.
- צריך פעם אחת מפתח Gemini בחינם: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) ← Create API key ← מדביקים באפליקציה ← שמירה.
- המפתח נשמר רק בטלפון שלכם ונשלח רק ל-Google.
- פודקאסט בינוני לוקח בערך דקה עד שלוש להכנה.

## פרטים טכניים
קובץ אחד: `index.html`.
- הפרשה של השבוע: [Hebcal](https://www.hebcal.com/).
- הטקסט: [Sefaria API](https://developers.sefaria.org/) (בלי טעמי המקרא, עם ניקוד, עם מספרי פרקים ופסוקים).
- הפודקאסט: Gemini Interactions API – המודל `gemini-3.8-flash` כותב את השיחה, ו-`gemini-3.8-flash-tts` מקריא אותה. אם Google משנה את שמות המודלים, אפשר לעדכן אותם בהגדרות שבאפליקציה.
- ההמרה ל-MP3 נעשית בטלפון עם הספרייה lamejs. אם היא לא נטענת, מקבלים קובץ WAV (גדול יותר).
